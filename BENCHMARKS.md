# CPU benchmark results

Generated by `python benchmark_cpu.py --markdown BENCHMARKS.md`.

Environment: CPython 3.13.1 on macOS-15.0-arm64-arm-64bit-Mach-O (arm64); 7 measured runs after one warm-up.

Execution path: production max-cycle dispatch.

| Case | Instructions/s (median) | Emulated cycles/s (median) | Real-time |
|---|---:|---:|---:|
| NOP dispatch | 1,389,901 | 5,559,603 | 1.33× |
| JR dispatch | 1,171,140 | 14,053,682 | 3.35× |
| JP dispatch | 1,117,251 | 17,876,014 | 4.26× |
| CALL/RET trampoline | 937,248 | 18,744,966 | 4.47× |
| 16-bit pair math | 920,207 | 8,700,138 | 2.07× |
| 8-bit ALU mix | 1,042,984 | 5,562,580 | 1.33× |
| High I/O load | 865,761 | 9,523,368 | 2.27× |

Real-time is measured against the DMG clock target of 4,194,304 cycles/s. These are isolated CPU microbenchmarks, not whole-emulator frame rates.

Reports without an `Execution path` line are not directly comparable: the older harness used the diagnostic instruction-limit loop and some cases stopped before their complete program.
